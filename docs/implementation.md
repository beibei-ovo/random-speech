# MVP 实现与验证记录

## 实现范围

| 模块 | 已实现的行为 |
| --- | --- |
| 桌面与权限 | Electron 主窗口、受限 preload 悬浮窗、托盘、单实例、权限校验、自定义本地协议与 CSP |
| 主题 | 12 个带稳定 ID 的中文概念题目、分类、滚动与锁定 |
| 准备 | 600/300 秒单调时钟、暂停继续、提前下一步、递增版本、防重复切换、每 4 秒快照 |
| 恢复 | 重启暂停、系统休眠暂停、录音中断保存、临时录音清理、服务中断可重试 |
| 录音 | 用户主动授权、音量检测、WebM/Opus、顺序确认写入、120 秒停止目标、回放与重录 |
| 反馈 | 可配置 HTTPS 兼容 Provider、离线演示、上传确认、引用结构校验、一次格式修复、单任务去重 |
| 复盘 | 原始转写不可覆盖、校正新增版本、反馈关联版本、同题新增演讲、帮助程度反馈 |
| 保存与删除 | SQLite 外键、音频独立文件、删除标记与关联清理、迟到响应拒绝、历史磁盘占用 |

## 技术取舍

首版结构化实体以 JSON 正文加关系外键存入 SQLite，避免双份模型映射；训练、演讲、转写、反馈、任务均是独立记录。题库随应用打包，训练保存题目快照。schema 版本为 1，拒绝打开高版本数据库；当前没有历史 schema 升级，未来迁移需新增备份与回滚验证。

默认演示 Provider 明确展示模拟内容，不用于评价真实表达。云端接入兼容 multipart `/audio/transcriptions` 和 JSON `/chat/completions`，同一 HTTPS 基础地址下分别配置模型。没有预置任何密钥，也没有公共额度后端。

网络超时为 90 秒，不自动重试网络或 429 请求；用户可以重试，并看到潜在重复计费提示。响应格式或引用不匹配时最多自动追加一次修复请求。服务请求不写正文日志；仅保存本地状态、版本和耗时事件。

本机统计提供训练数与完成反馈数。7 日留存的跨用户统计、供应商用量与价格汇总未实现，因为首版没有用户标识、集中采集或已选定的计费供应商。

## 自动验证入口

| 命令 | 覆盖内容 |
| --- | --- |
| npm test | 计时、恢复、协议路径与音频范围、反馈引用、有限重试、界面锁题 |
| npm run test:integration | Electron ABI 下 SQLite 读写、分块顺序、版本保留、重复任务、重讲、恢复、关联删除与迟到响应 |
| npm run test:docs | 文档结构、相对链接与 13 个验证器回归场景 |
| npm run test:e2e | 真正 Electron 双窗口、准备计时、MediaRecorder、演示反馈、校正、重讲与删除 |
| npm run package | 生产构建、原生依赖与 NSIS 安装包 |

## 发布前真机专项

自动测试不替代实际麦克风、系统休眠与唤醒、设备拔出、其他应用遮挡、系统静音和安装升级验收。真实云端测试需要用户配置有效服务，不能用演示结果代替中文识别质量、费用、时延和留存验证。

Windows 安装包用于本机或受控内部验证。向外部分发统一额度之前，还需完成轻量服务端密钥保护、额度与限流、供应商留存确认、代码签名和新机器安装验收。

## 本次验证结果

2026-09-14，在 Windows 10 19045 x64、Intel Core i7-11800H、Node.js 24.13.0 上完成验证。锁定 Electron 41.10.3、better-sqlite3 12.11.1，完整依赖树见锁文件。

14 项 Vitest 测试、Electron ABI 数据库集成、13 项文档检查器回归、类型检查与生产构建均通过。完整桌面 E2E 在修复首次加载接口注册时序后连续运行两次通过。安装包应用冒烟检查验证了 SQLite 访问、双窗口、renderer sandbox、contextIsolation 和悬浮置顶。依赖审计为 0 个已知漏洞。

NSIS 安装包约 99.5 MiB，解包目录约 402 MiB。首次打包启动采样约 1.18 秒，后续同机有缓存启动约 0.62 秒；这些是自动测试启动到首页可见的单次观测，不是新机器冷启动承诺。初次采样所有应用进程工作集相加约 491 MiB、私有内存约 257 MiB；共享页可能重复计入工作集。当前未完成稳定空闲、录音和分析阶段的 CPU/内存长时间基准，不能把启动时 CPU 首次采样当成稳态性能结论。

可执行 `node tests/integration/packaged-smoke.mjs` 重做打包运行检查，生成的本机原始指标位于 `release/validation.json`，界面截图位于 `release/preview.png`。安装器构建和解包应用运行已验证；尚未在全新机器执行安装、卸载或升级测试。
